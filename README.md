# 本編を基にした閲覧専用図鑑

本編のファイルをコピーし、本編の図鑑画面・地図操作・各タブ・収録データを土台にしています。都道府県から市区町村の地図への切替、過去の市区町村、湖、未所属、町・丁目、旧国・藩、島の各画面を利用できます。市区町村の詳細の下に2020年の統計を表示します。町丁詳細には所属市区町村全体の統計を参考として表示し、町丁単独の数字とは区別しています。世界地図は対戦ゲームの画面であるため、閲覧専用版からは開けません。

図鑑を直接開き、画面上のゲーム内能力・所持情報・対戦ボタン等を非表示にしています。地形の色は本編の色を表示しており、所有状況を示すものではありません。モデルは本編の地形モデルを使用し、ドラッグで回転できます。モデルは簡略化された平面輪郭を一定の厚みで押し出したもので、実際の標高を表しません。地形・境界は参考表示であり、測量などには使用できません。

町丁等の境界は2020年国勢調査の元ゲーム収録分です。旧国・藩や過去の市区町村なども、収録範囲・時点や境界の簡略化に制約があります。各タブの出典および `SOURCE-NOTES.md`、`CREDITS.md`、`LICENSES.txt` を参照してください。© OpenStreetMap contributors。統計は2020年時点で、行政区画が現状と異なる場合や市・行政区の重複があります。

## 起動方法

GitHub Pagesなどの静的サーバーで、ZIPを展開した中身を公開してください。ローカルでは、このフォルダで `python3 -m http.server 8000` を実行し、http://localhost:8000/ を開きます。HTMLを直接開く方法には対応しません。通信状況によっては外部資料の地図が表示できないことがあります。

本編とは別の保存領域を使用します。本編のゲームプログラム・データも内部に含まれていますが、対戦・ガチャ画面を利用するための配布物ではありません。元の全国版本編ファイルは変更していません。
